Dónde vive el backlog en este curso
Decisión del curso: el backlog es texto que vive en el repo, más tickets en Jira, en el tablero del proyecto. Concretamente:

Un directorio de documentación en el repo: historias con criterios de aceptación, versionadas junto al código, igual que el PRD y que la configuración del propio agente. El backlog no vive en la cabeza de nadie ni en un documento olvidado.

Historias y tickets en Jira: la historia sube como issue y sus tickets como subtareas suyas, vía el MCP de Atlassian/Jira conectado al tablero del proyecto. Mismo prompt, el agente los crea sin salir de la terminal. GitHub queda para el código y los PRs (gh pr create).

📌 FlowSync y FLOW no son dos proyectos: son el nombre y la clave. El proyecto se llama FlowSync, y FLOW es la clave que Jira le antepone a todo lo que crea en su tablero, así que en pantalla vas a ver FLOW-… por todas partes. Es la misma cosa nombrada dos veces: una para las personas y otra para la herramienta. Merece la pena saberlo antes de verlo, porque el salto de un nombre al otro parece un cambio de proyecto y no lo es.

💡 Por qué en el repo + tu gestor y no en una herramienta de PM aislada: coherencia con todo el curso (una sola fuente, versionada, que la IA relee como contexto de alta calidad). Y el artefacto es portable: una historia con criterios es texto. Aquí usamos Jira, pero si tu equipo vive en GitHub Issues o Linear, es el mismo prompt con otro MCP. El curso no te ata a una herramienta: te enseña el artefacto.

💬 CLI o MCP: el MCP no es la única vía. Para operaciones que el modelo ya domina (un gh pr create, leer un diff), una CLI puede salir más barata en contexto que cargar un MCP entero; el MCP brilla cuando necesitas descubrir la API o datos tipados. Elige por caso, no por dogma.

🛡 Seguridad MCP (mención obligada): el ecosistema MCP tuvo CVEs (RCE en un MCP no oficial de Atlassian; vulnerabilidad de transport STDIO; prompt injection en MCPs de comunidad). Guardarraíles: usa MCPs oficiales cuando existan, mantenlos actualizados, lee el código de los de comunidad antes de usarlos en serio, y aprovecha los hooks del agente, los ganchos que se disparan antes o después de una acción, para interceptar llamadas peligrosas.
